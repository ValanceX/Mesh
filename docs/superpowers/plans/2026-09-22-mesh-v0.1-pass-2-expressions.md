# MESH v0.1 — Pass 2 (Expressions) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Widen the MPRX grammar and pipeline (grammar → `mesh-syntax` → `mesh-parser` → `mesh-semantic` → `mesh-compiler`) to support `{...}` expression syntax in attribute values, covering exactly the three node kinds the design spec names for this pass: Literal, Reference, and MemberAccess. `<page title={user.name} />` must parse, lower, and compile cleanly, with the reference/member-access data provably surviving into the Semantic IR.

**Architecture:** Bottom-up, one layer at a time (grammar → syntax → parser → semantic → compiler-test-coverage) — unlike Pass 1, the pipeline's connectivity is already proven end-to-end, so this pass only needs to widen what flows through it, not re-wire the plumbing. `mesh-cli` and `mesh-compiler`'s production code are untouched: `compile()`'s signature doesn't change, only the richer `AttributeValue`/`Expression` shape flowing through `mesh-syntax` and `mesh-semantic`. This is the first breaking change to `Attribute`'s shape since Pass 1 shipped — string-only attribute values become `AttributeValue::String(...) | AttributeValue::Expression(...)`.

**Tech Stack:** Same as Pass 1 (Rust, Tree-sitter, `tree-sitter-cli` via npm). No new external crates needed — `Box<Expression>` for the recursive `MemberAccess.object` field uses only `std`.

**Spec:** `docs/superpowers/specs/2026-09-21-mesh-v0.1-roadmap-design.md` (Pass 2 row of the build-order table)

## Global Constraints

- MESH must not depend on `nexus` or `port`.
- No component-model type checking in v0.1 — this pass adds expression *parsing and structural representation* only. Do not add reference resolution, type checking, or validation of what a `Reference`/`MemberAccess` points to.
- Scope is strictly Literal, Reference, MemberAccess. Do NOT add UnaryExpression, BinaryExpression, ConditionalExpression, ArrayExpression, ObjectExpression, or CommandInvocation — those are Pass 3.
- Do NOT add nested elements, `on.` event bindings, or structural-validation diagnostics (duplicate attributes, mismatched tags) — those are Pass 4.
- Every dependency added via `cargo add` / `npm install` — never hand-pinned versions. This pass adds no new dependencies, so this mostly just means: don't add any without reason.
- Generated Tree-sitter output (`grammar/tree-sitter-mprx/src/*`) is committed, same as Pass 1.
- `mesh-cli`'s production code (`crates/mesh-cli/src/main.rs`) is not expected to need any changes — if you find yourself editing it, stop and reconsider: `compile()`'s public signature is unchanged, so the CLI shouldn't need to know anything new.

```js
module.exports = grammar({
  name: 'mprx',

  extras: $ => [/\s/],

  rules: {
    source_file: $ => $.element,

    element: $ => choice(
      $.self_closing_element,
      $.container_element,
    ),

    self_closing_element: $ => seq(
      '<',
      field('name', $.identifier),
      repeat($.attribute),
      '/>',
    ),

    container_element: $ => seq(
      '<',
      field('name', $.identifier),
      repeat($.attribute),
      '>',
      optional(field('text', $.text)),
      '</',
      $.identifier,
      '>',
    ),

    attribute: $ => seq(
      field('name', $.identifier),
      '=',
      field('value', choice($.string, $.expression_block)),
    ),

    expression_block: $ => seq(
      '{',
      field('expression', $.expression),
      '}',
    ),

    expression: $ => choice(
      $.literal,
      $.reference,
      $.member_access,
    ),

    literal: $ => choice(
      $.string,
      $.number_literal,
    ),

    number_literal: $ => /-?[0-9]+(\.[0-9]+)?/,

    reference: $ => $.identifier,

    member_access: $ => seq(
      field('object', choice($.reference, $.member_access)),
      '.',
      field('property', $.identifier),
    ),

    string: $ => seq(
      '"',
      optional(field('value', $.string_content)),
      '"',
    ),

    string_content: $ => /[^"]*/,

    text: $ => /[^<]+/,

    identifier: $ => /[a-zA-Z_][a-zA-Z0-9_-]*/,
  },
});
```

Note what changed from Pass 1: only the `attribute` rule's `value` field gained a second alternative (`$.expression_block`), plus six new rules below it. Everything else is byte-identical to Pass 1's grammar.

Replace the existing `lower_attribute` function with:

```rust
fn lower_attribute(node: Node, source: &str) -> Attribute {
    let name = node
        .child_by_field_name("name")
        .map(|n| text_of(n, source))
        .unwrap_or_default();

    let value_node = node.child_by_field_name("value");
    let value = match value_node {
        Some(v) if v.kind() == "string" => AttributeValue::String(lower_string(v, source)),
        Some(v) if v.kind() == "expression_block" => {
            let expr_node = v.child_by_field_name("expression");
            AttributeValue::Expression(match expr_node {
                Some(e) => lower_expression(e, source),
                None => Expression::Reference(Reference {
                    name: String::new(),
                    span: span_of(v),
                }),
            })
        }
        Some(v) => AttributeValue::String(lower_string(v, source)),
        None => AttributeValue::String(StringLiteral {
            value: String::new(),
            span: span_of(node),
        }),
    };

    Attribute {
        name,
        value,
        span: span_of(node),
    }
}

fn lower_string(node: Node, source: &str) -> StringLiteral {
    StringLiteral {
        value: node
            .child_by_field_name("value")
            .map(|n| text_of(n, source))
            .unwrap_or_default(),
        span: span_of(node),
    }
}

fn lower_expression(node: Node, source: &str) -> Expression {
    // `node` is an `expression` node; its single child is the real variant.
    let inner = node.child(0).unwrap_or(node);
    match inner.kind() {
        "literal" => Expression::Literal(lower_literal(inner, source)),
        "reference" => Expression::Reference(lower_reference(inner, source)),
        "member_access" => Expression::MemberAccess(lower_member_access(inner, source)),
        _ => Expression::Reference(lower_reference(inner, source)),
    }
}

fn lower_literal(node: Node, source: &str) -> Literal {
    let inner = node.child(0).unwrap_or(node);
    match inner.kind() {
        "string" => Literal::String(lower_string(inner, source)),
        _ => Literal::Number(NumberLiteral {
            value: text_of(inner, source),
            span: span_of(inner),
        }),
    }
}

fn lower_reference(node: Node, source: &str) -> Reference {
    Reference {
        name: text_of(node, source),
        span: span_of(node),
    }
}

fn lower_member_access(node: Node, source: &str) -> MemberAccess {
    let object = node
        .child_by_field_name("object")
        .map(|o| match o.kind() {
            "member_access" => Expression::MemberAccess(lower_member_access(o, source)),
            _ => Expression::Reference(lower_reference(o, source)),
        })
        .unwrap_or_else(|| Expression::Reference(lower_reference(node, source)));

    let property = node
        .child_by_field_name("property")
        .map(|p| text_of(p, source))
        .unwrap_or_default();

    MemberAccess {
        object: Box::new(object),
        property,
        span: span_of(node),
    }
}
```

Note the old inline string-lowering code that used to live directly in `lower_attribute` (reading `value_node.and_then(|v| v.child_by_field_name("value"))`) is now the standalone `lower_string` helper, reused by both the direct-string-attribute case and the `Literal::String` case inside expressions.

//! Semantic model for MPRX.
//!
//! For v0.1, this crate builds the Semantic IR from the `mesh-syntax` AST
//! and performs structural pass-through only. It does not yet resolve
//! component/prop/binding references against an external component model —
//! that requires a typed component model that doesn't exist yet.

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Element {
    pub name: String,
    pub attributes: Vec<Attribute>,
    pub children: Vec<Text>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Attribute {
    pub name: String,
    pub value: AttributeValue,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum AttributeValue {
    String(String),
    Expression(Expression),
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Literal {
    String(String),
    Number(String),
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Expression {
    Literal(Literal),
    Reference(String),
    MemberAccess {
        object: Box<Expression>,
        property: String,
    },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Text {
    pub value: String,
}

pub fn lower(ast: &mesh_syntax::Element) -> Element {
    Element {
        name: ast.name.clone(),
        attributes: ast.attributes.iter().map(lower_attribute).collect(),
        children: ast
            .children
            .iter()
            .map(|t| Text {
                value: t.value.clone(),
            })
            .collect(),
    }
}

fn lower_attribute(attribute: &mesh_syntax::Attribute) -> Attribute {
    Attribute {
        name: attribute.name.clone(),
        value: lower_attribute_value(&attribute.value),
    }
}

fn lower_attribute_value(value: &mesh_syntax::AttributeValue) -> AttributeValue {
    match value {
        mesh_syntax::AttributeValue::String(literal) => AttributeValue::String(literal.value.clone()),
        mesh_syntax::AttributeValue::Expression(expression) => {
            AttributeValue::Expression(lower_expression(expression))
        }
    }
}

fn lower_expression(expression: &mesh_syntax::Expression) -> Expression {
    match expression {
        mesh_syntax::Expression::Literal(literal) => Expression::Literal(lower_literal(literal)),
        mesh_syntax::Expression::Reference(reference) => Expression::Reference(reference.name.clone()),
        mesh_syntax::Expression::MemberAccess(member) => Expression::MemberAccess {
            object: Box::new(lower_expression(&member.object)),
            property: member.property.clone(),
        },
    }
}

fn lower_literal(literal: &mesh_syntax::Literal) -> Literal {
    match literal {
        mesh_syntax::Literal::String(s) => Literal::String(s.value.clone()),
        mesh_syntax::Literal::Number(n) => Literal::Number(n.value.clone()),
    }
}
