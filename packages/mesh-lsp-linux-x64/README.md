# @valancex/mesh-lsp-linux-x64

The native [`mesh-lsp`](https://github.com/ValanceX/Mesh) language server, built for linux on x64.

Don't install this package directly: install [`@valancex/mesh-lsp`](https://www.npmjs.com/package/@valancex/mesh-lsp), which depends on it (and on the packages for the other platforms, of which npm installs only yours) and starts the server.
